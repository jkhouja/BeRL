📝 BASIC USAGE
──────────────────────────────────────────────────────────────────────────────
  python scripts/convert_dailydialog.py [OPTIONS]

⚙️  COMMON OPTIONS
──────────────────────────────────────────────────────────────────────────────
  --config FILE               Load config from YAML/JSON file
  --output-name NAME          Output filename (default: DailyDialog)
  --sample-size N             Limit to N examples (default: all)
  --split {train,val,test}    Dataset split (default: train)

🎨 PROMPT CONFIGURATION
──────────────────────────────────────────────────────────────────────────────
  Preset Styles:
    --system-prompt-style {default|research}
    --prompt-style {simple|detailed|baseline}

  Custom:
    --system-prompt "..."       Custom system prompt
    --user-template "..."       Custom user template
                                Use {dialogue_history} and {responding_speaker}

  Advanced:
    --generation-prefix "..."   Add prefix (e.g., "<think>")
    --include-system-in-prompt  Include system in prompt field

📦 RESPONSE FORMATTING
──────────────────────────────────────────────────────────────────────────────
  --add-response-tags           Wrap responses in tags
  --response-tag-open "..."     Opening tag (default: <answer>)
  --response-tag-close "..."    Closing tag (default: </answer>)

🔍 FILTERING
──────────────────────────────────────────────────────────────────────────────
  --min-turns N                 Min conversation turns (default: 4)
  --max-turns N                 Max conversation turns
  --min-response-words N        Min words per response (default: 5)
  --max-response-words N        Max words per response
  --limit-turn N                Only include turns >= N

🏷️  METADATA
──────────────────────────────────────────────────────────────────────────────
  --ability TAG                 Ability tag (default: conversation_generation)
  --data-source SOURCE          Data source (default: dailydialog)

💡 EXAMPLES
──────────────────────────────────────────────────────────────────────────────
  1. Basic conversion with 1000 samples
     $ python scripts/convert_dailydialog.py --sample-size 1000

  2. Research-style prompts
     $ python scripts/convert_dailydialog.py \
         --system-prompt-style research \
         --prompt-style detailed

  3. Chain-of-thought format
     $ python scripts/convert_dailydialog.py \
         --generation-prefix "<think>" \
         --add-response-tags

  4. Using config file
     $ python scripts/convert_dailydialog.py \
         --config scripts/dailydialog_config_example.yaml

  5. Later turns only (more developed conversations)
     $ python scripts/convert_dailydialog.py \
         --limit-turn 2 \
         --min-turns 6

  6. Custom everything
     $ python scripts/convert_dailydialog.py \
         --system-prompt "You are an expert conversation analyst." \
         --user-template "Given:\n{dialogue_history}\n\nPredict {responding_speaker}:" \
         --add-response-tags \
         --response-tag-open "[ANSWER]" \
         --response-tag-close "[/ANSWER]"

📊 OUTPUT FORMAT
──────────────────────────────────────────────────────────────────────────────
  Parquet file with columns:
    • prompt_len              Prompt length (filled during tokenization)
    • response_words          Number of words in response
    • data_source             Dataset identifier
    • prompt                  Chat-formatted prompt (list of dicts)
    • raw_system_prompt       System prompt string
    • raw_user_prompt         User prompt string
    • prompt_for_pp           Full prompt for perplexity calculation
    • ability                 Ability tag
    • reward_model            Ground truth and style
    • metadata                Conversation details
    • raw_prompt              Full chat template
    • generation_prefix       Optional generation prefix
    • response_with_tags      Optional tagged response

🔗 PROGRAMMATIC USAGE
──────────────────────────────────────────────────────────────────────────────
  from convert_dailydialog import DailyDialogConverter

  config = {
      'system_prompt_style': 'research',
      'prompt_style': 'detailed',
      'sample_size': 1000,
  }

  converter = DailyDialogConverter(config=config)
  dataset = converter.download_dataset()
  df = converter.convert(dataset)
  df.to_parquet('output.parquet')
