# Experiment logs

Per-run self-contained summaries live here as `<RUN_NAME>.md` (RUN_NAME = tracker Run name =
WandB run name = log filename stem). Written and appended-to by the execution agents — see the
`join-experiments` and `log-results` skills. One file per run: hypothesis, implementation/knobs,
exact launch command, debugging notes, findings vs baseline, and metadata (WandB link, log path,
owner host, rerun line).
